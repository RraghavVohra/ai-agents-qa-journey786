- Filter/category tabs: check the 'active' class on the clicked element (assert_type 'element_class'), not the resulting content text - content is often truncated with '..' and won't match exactly.
- Social/external links open in a new tab (target='_blank') - check the real href via assert_type 'element_href', don't try to navigate and check current_url for these.
- For images, always use assert_type 'image_loaded', never 'element_text' - images have no text content.
- A floating chat widget can visually overlap other buttons - if a click times out with 'intercepts pointer events', that's usually just this overlap, not a wrong selector.- When interacting with category filters, verify not just the active state with a class assertion but also ensure the content list updates accordingly.
- Always use valid CSS selectors; 'querySelectorAll' does not support pseudo-classes like ':contains'.
